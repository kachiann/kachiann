# Hi, I'm Kachi 👋

**Data Scientist, PhD in Computational Mathematics** — explainable machine learning, MLOps and retrieval-augmented AI, built on five years of peer-reviewed numerical research.

I take problems from raw data to working models: EDA, feature engineering, modelling and evaluation, then the tracking, orchestration and drift monitoring that keep a model reliable once it's in use.

- 📈 Building explainable ML models with tracked experiments (XGBoost · SHAP · MLflow)
- ⚙️ Taking models to production with orchestration, CI/CD and drift monitoring (Prefect · Docker · Kubernetes · Evidently)
- 🤖 Shipping RAG and LLM applications grounded in real sources, not model guesswork
- 🎓 Lectured in Data Analytics & Machine Learning (MSc) at Berlin School of Business & Innovation, 2024–2026
- 📄 PhD in Computational Mathematics (quasi-Monte Carlo methods) · 5 peer-reviewed publications · [Google Scholar](https://scholar.google.com/citations?user=Qe94rEoAAAAJ&hl=en) · [ORCID](https://orcid.org/0000-0003-1081-4481)
- 📝 Writing on [Medium](https://medium.com/@kachiann) about applied data science, ML and statistics
